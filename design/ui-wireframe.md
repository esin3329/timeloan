# 타임라인 UI 와이어프레임

화면 하단 중앙, 가로 1줄. 한 눈에 **"빌린 양 / 남은 양 / 예약된 입력"** 이 보여야 한다.

```
        ┌───────────────────────────────────────────────────┐
        │  ◀ 빚 구간      │   남은 시간      │  예약 입력    │
        │  ██▊            │   ██████░░░░     │  [1][2][3][ ] │
        │  -2.4s          │    3.1s          │  대시 점프 대시│
        └───────────────────────────────────────────────────┘
              빨강              청록               노랑
```

## 상태별 표현

| 상태 | 게이지 | 배경 | 이펙트 |
|---|---|---|---|
| Borrow 중 | 청록 바가 왼쪽으로 닳음 | 약간 어두움 + 속도선 | 가장자리 비네트 |
| 빚 구간 (T<0) | 바가 0선 왼쪽으로, 빨강 | 붉은 틴트 | 심장 박동 느낌의 미세 펄스 |
| Repay (수동) | 바가 급격히 회복 | 밝은 틴트 + 강한 속도선 | 화면 흔들림 약간 |
| 강제 상환 | 동일하나 **경고 테두리 점멸** | 강한 붉은 틴트 | 예약 슬롯이 잠김 |

## 예약 슬롯 규칙

- 슬롯 4개. Borrow/정상 구간에서만 배치 가능
- Repay 구간에는 **잠김 표시**(자물쇐) — 실시간 입력 거부를 시각적으로 설명
- 각 슬롯은 커맨드 아이콘 + 예상 실행 시점(작은 점) 표시
- 실행된 슬롯은 순차적으로 소멸

## 가독성 원칙 (실패하면 다 망하는 부분)

1. **현재 타임스케일은 색으로만, 수치는 작게** — 숫자를 읽게 만들면 실패
2. 0선(=파산선)은 화면 중앙에 고정, 항상 보이게
3. 강제 상환 진입 1초 전 경고(게이지 점멸 + 사운드 1회)
4. 예약 입력은 "미래에 일어날 일"이므로 타임라인에서 **오른쪽으로 갈수록 미래**

## 미해결 (W2 실험 항목)

- 타임라인이 화면 하단 vs 플레이어 캐릭터 주변 링 게이지 — 어느 쪽이 고속 구간에서 더 잘 보이나
- 예약 실행 시점을 게임시간(초)로 표시할지, "몇 프레임 후" 도트로 표시할지
