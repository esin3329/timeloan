# R1~R8 레벨 초안

공통: 단일 화면 방(640×360 논리 해상도), 진입 시 게이지 `T = 6.0` 리셋.

---

## R1 — 빌리는 법만
- 구조: 좌측 진입 → 중앙 탄막 복도(느린 발사체 6개) → 우측 출구
- 장치: 탄막은 정상 속도로는 통과 불가, Borrow로만 가능
- 목표: **게이지가 줄어든다는 사실**만 체감. 상환 개념 없음
- 클리어 조건: 우측 출구 도달

## R2 — 강제 상환 체험
- 구조: R1보다 긴 탄막 복도 + 중간에 회복 아이템 없음
- 장치: 복도 길이를 `T` 최대치보다 길게 → 반드시 빚 구간 진입 → 바닥 도달 → 강제 상환
- 목표: "통제력을 잃는 경험"을 먼저 준다 (불쾌해야 한다)
- 실패 유도 후 즉시 리스폰, 페널티 없음

## R3 — 스스로 갚기
- 구조: R2 동일하지만 복도 중간에 **안전 포켓**(적 사거리 밖) 존재
- 장치: 안전 포켓 벽에 "R = 갚기" 아이콘. 누르면 회복률 0.9(이자 10%)
- 목표: 강제 상환(0.6)보다 수동 상환(0.9)이 유리함을 스스로 발견
- 검증: 이 방에서 플레이어가 **자발적으로 R을 누르는가** (핵심 지표)

## R4 — 예약 입력 첫 사용
- 구조: 짧은 복도 + 도약 지점 1개
- 장치: Repay 구간(고속)에서 점프해야만 넘는 간격
- 목표: 타임라인에 점프 1개를 배치하는 법 학습
- UI: 이 방에서만 예약 슬롯이 크게 강조됨

## R5 — 예약 3연타
- 구조: 대시 → 점프 → 대시 순서로만 통과 가능한 복도
- 장치: 고속 구간에서 정확한 순서·간격 필요
- 목표: 예약 입력의 **타이밍 감각**

## R6 — 레드존 (이자 2배)
- 구조: 회복률 0.45 구역 (일반 0.9의 절반)
- 장치: 바닥 색이 붉고, Slow 사용 시 게이지가 2배로 닳는 시각 피드백
- 목표: "어디서 빌릴지"라는 공간적 판단

## R7 — 첫 진짜 판단
- 구조: 적 2기 + 안전 포켓. 포켓에서 갚으면 시간이 걸리지만 안전
- 장치: 두 경로 모두 클리어 가능, 효율 차이 존재
- 목표: 리스크 테이킹 vs 안전의 선택이 **플레이어 성향**으로 드러나는지 관찰

## R8 — 총 예산 방 (최종 검증)
- 구조: 3개 구역, 총 Borrow 가능량이 명시적 제한(예: 8초)에 가깝게 설계
- 장치: 한 곳에서 낭비하면 뒤가 막힘
- 목표: **클리어 경로가 2개 이상** 나와야 이 방은 성공
- 지표: 평균 시도 2~5회
